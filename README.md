# แอบฟังอยู่นะจ้ะ 👂
**by LeRaxs** — BetterDiscord Plugin

> ฟังหรือพูดในห้องเสียงได้แม้จะแสดงว่าปิดเสียงอยู่

---

## คืออะไร?

ปลั๊กอินนี้ทำให้คุณสามารถ **Fake Mute / Fake Deafen** ใน Discord ได้  
หมายความว่า — คุณจะดูเหมือนปิดไมค์หรือปิดหูฟังในสายตาคนอื่น แต่จริงๆ ยังได้ยินเสียงหรือพูดได้ตามปกติ

---

## วิธีติดตั้ง

1. ติดตั้ง [BetterDiscord](https://betterdiscord.app/) ก่อน
2. ดาวน์โหลดไฟล์ [`FakeMutebyLeRaxs.plugin.js`](https://github.com/leraxs001/BetterDiscord-FakeMute-by-LeRaxs/blob/main/FakeMutebyLeRaxs.plugin.js)
3. วางไฟล์ไว้ที่โฟลเดอร์ปลั๊กอินของ BetterDiscord
   - Windows: `%appdata%\BetterDiscord\plugins\`
   - Mac: `~/Library/Application Support/BetterDiscord/plugins/`
4. เปิด Discord → ตั้งค่า → Plugins → เปิดใช้งาน **แอบฟังอยู่นะจ้ะ**

---

## วิธีใช้งาน

| วิธี | รายละเอียด |
|------|------------|
| **ปุ่มใน UI** | กดปุ่มที่ปรากฏข้างๆ ปุ่มตัดการเชื่อมต่อในห้องเสียง |
| **Right-click menu** | คลิกขวาที่ไอคอนเสียง → เลือก Fake Mute/Deafen โดย LeRaxs |

> ⚠️ ต้องเข้าห้องเสียงก่อนถึงจะเปิดใช้งานได้

### ขั้นตอนที่ถูกต้อง

1. เข้าห้องเสียงก่อน
2. กดปิดไมค์ (Mute) หรือปิดหูฟัง (Deafen) ใน Discord ตามปกติ
3. **แล้วค่อยกดปุ่ม Fake Mute** — ปลั๊กอินจะล็อกสถานะปัจจุบันไว้
4. หลังจากนั้นกด Unmute / Undeafen ใน Discord ได้เลย — คนอื่นจะยังเห็นว่าคุณปิดเสียงอยู่

> 💡 เหตุผลที่ต้องทำแบบนี้ — ปลั๊กอินทำงานโดยกรอง packet ที่จะส่งสถานะใหม่ไปยังเซิร์ฟเวอร์ Discord ถ้ากด Fake Mute ก่อนโดยไม่ได้ปิดไมค์ก่อน Discord จะส่ง packet "เปิดไมค์" ออกไปก่อนแล้ว ปลั๊กอินจึงจะกรองได้แค่ packet หลังจากนั้น

## การตั้งค่า

เข้าไปที่ Settings → Plugins → แอบฟังอยู่นะจ้ะ → ⚙️

| ตัวเลือก | คำอธิบาย |
|----------|----------|
| **แสดงปุ่มเปิด/ปิด** | แสดงหรือซ่อนปุ่มใน UI ของห้องเสียง |
| **เสียงเปิด/ปิด** | เล่นเสียงเมื่อเปิดหรือปิดฟีเจอร์ |
| **Fallback DOM** | ใส่ปุ่มกลับเข้าไปใหม่อัตโนมัติถ้า Discord รีเรนเดอร์ |

---

## ทำงานอย่างไร?

ปลั๊กอินดักจับ WebSocket packet ที่ Discord ส่งเพื่ออัปเดตสถานะ `self_mute` และ `self_deaf`  
เมื่อเปิดใช้งาน packet เหล่านั้นจะถูกกรองทิ้ง ทำให้เซิร์ฟเวอร์ Discord ไม่ได้รับการอัปเดตสถานะ
